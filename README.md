# JavaScript Advanced Basic – Day 4

A simple restaurant ordering form built with HTML and JavaScript to practice Regex validation, Local Storage, and Session Storage.

## Features

- Validate the username: cannot be empty or contain spaces.
- Validate the password: at least 8 characters and includes a number.
- Validate the phone number: exactly 10 digits, starting with 07.
- Display a welcome message after successful validation.
- Save the selected order in Local Storage.
- Save the username in Session Storage.
- Display saved data when the page loads.

## Project Files

- `index.html`: The form and result elements.
- `fun.js`: Input validation, storage, and displaying results.

## How to Run

1. Download the project.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Fill in the form and click Submit.
